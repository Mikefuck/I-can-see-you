# 数据与隐私说明

Focus Ledger 用于自托管的应用使用时间记录。客户端首次安装后需要用户配置并主动开启采集；请在本人或已知情同意的用户设备上使用。此文说明当前实现的数据流，实际部署者负责所运行实例的账户、访问范围和数据管理。

## 记录什么

- 前台应用名称、进程名或 Android 应用标识、使用时段和时长。
- 设备名称、平台、客户端版本及用于识别设备的标识。Windows 系统标识和 Android 安装范围内标识以摘要参与设备识别，不上传原始系统标识；协议还包含客户端设备 UUID。
- 按设置采集的电池、电源、开关机、休眠等设备状态。
- 启用音乐同步时的当前曲名、歌手、专辑、播放器及播放状态，来自系统媒体会话；不保存听歌历史。

不采集窗口标题、截图、键盘输入、文件内容或进程完整路径。音乐功能不录音、不上传通知正文。应用名称与时间本身也可能透露个人习惯，请谨慎设置公开范围。

## 数据发送和查看

客户端将记录发给用户填写的服务端；主地址和备用地址应指向同一服务端。断网时先保留在本机队列，恢复后补传。项目不提供默认的托管数据接收服务。

上传权限和设备归属按账户隔离，但网页展示有独立的可见范围：

| 账户公开设置 | 谁可以通过看板查看 |
| --- | --- |
| 未公开 | 该服务器的所有已登录成员 |
| 已公开 | 包括未登录访客在内的访问者 |

Android 小组件访问成员记录需要独立的只读授权；其权限与上传密钥分开，可以撤销。服务器管理员能够管理实例、数据文件和备份，因此只向可信服务器上传。

## 本机凭据与保存位置

- Windows 配置与队列位于 `%LOCALAPPDATA%\FocusLedger`。上传密钥使用当前 Windows 账户的 DPAPI 加密；管理密码和管理会话只保存在内存。未上传缓存最多 30 天 / 100,000 条，已上传记录最多 7 天。
- Android 上传密钥及小组件令牌使用 Android Keystore 保护，管理密码和会话不持久化。配置和数据库不参与系统云备份或设备迁移。
- 服务端使用 SQLite，密码采用哈希存储，上传密钥和小组件令牌只保存摘要。数据卷、客户端队列和备份仍包含实际使用记录，应限制文件访问权限。

## 保留与清理

服务端保留天数可配置为 1–365 天，查询和定时清理受此范围限制。部署者应对备份执行同样的保留策略。

暂停采集会停止新增采样，已有待上传记录仍可补传；需要完全停止 Windows 程序时应从托盘退出，Android 可停止服务。Windows 卸载保留本机配置与缓存，彻底清理方法见 [客户端说明](../client/README.md)。Android 卸载会删除本机应用数据。重置密钥、撤销小组件授权与清除记录是不同操作。

公网服务使用 HTTPS；安装、配置与备份方法见 [服务端教程](../server/README.md)。发现凭据泄露或访问控制问题时按 [安全说明](../README.md#安全说明) 报告。
