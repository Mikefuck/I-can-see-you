# 专注记录 · Android

原生 Android 客户端，包名 `com.focusledger.android`，试用版 **0.1.2**。支持 Android 9（API 28）及以上，面向 Android 16（API 36）构建；无需 Root。纯 Java / Android 系统组件实现，没有内置第三方运行 SDK。现有 Focus Ledger 服务端 r10 可直接使用，不需要为安卓修改部署。

0.1.2 重做手机界面：五个入口改为线条图标导航，选中胶囊平滑移动；页面按导航方向轻移淡入，连续点击以最后一次选择为准，系统关闭动画时立即显示。统一浅色与深色下的圆角按钮、输入框、开关、权限选项和看板工具栏；总览突出今日时长、采集状态及主要操作，记录使用更紧凑的列表。按钮移除系统默认灰底和阴影，保留按下涟漪与足够的触摸区域。打开和返回内置看板也有过渡动画。

沿用原签名，可直接覆盖安装 0.1.0 / 0.1.1。包含 0.1.1 的首次启动修复：先创建窗口，再设置系统栏。

同时修复本机今日时长与排行被多算的问题：时段裁剪明确按整数时间比较，约 2.5 小时的记录不会再误算成 30 小时。跨午夜的记录只计入各天实际重叠的部分。升级后重新查询已有记录即可显示正确数值，无需清空缓存或重新上传。

界面预览使用隔离的示例数据生成：[浅色总览](docs/ui/light-0.png)、[深色总览](docs/ui/dark-0.png)、[连接设置](docs/ui/light-2.png)、[后台守护](docs/ui/light-3.png)、[小屏大字体](docs/ui/large-text-0.png)。

## 安装与首次接入

1. 将 [FocusLedger-android.apk](release/FocusLedger-android.apk) 发送到手机，在文件管理器中打开，按系统提示允许该来源安装。版本更新用同签名 APK 覆盖安装；卸载会删除本机未上传的记录和密钥。
2. 打开「连接」，填写完整主地址、备用地址（可留空）、上传密钥和设备名称，点击「验证连接并保存」。两个地址必须指向同一个服务端；公网建议 HTTPS。
3. 也可以在「服务端」登录账户，生成自己的上传密钥并接入。生成新密钥会让该账户的旧密钥立即失效，其他设备也需要更新密钥。新密钥先保存在加密草稿中，接入失败可以重试。
4. 在「保活」授予使用情况访问权限，允许通知，按需豁免电池优化。
5. 回到「总览」点击「开始 / 继续」。系统通知提供暂停、上传和停止入口。首次安装不会自行开始采集。

上传密钥由 Android Keystore 的 AES-GCM 加密保存；管理密码和管理登录会话仅保存在内存。本机配置和数据库不参与系统云备份或设备迁移。设备识别只发送安装签名与系统用户范围内 `ANDROID_ID` 的 SHA-256 摘要，不发送原始标识。

## Redmi K90 / 澎湃 OS 3 配置

在「保活」选择「小米优化」。小米系设备首次默认选择此模式；可随时切回「通用安卓」。

1. 开启使用情况访问权限。
2. 允许持续记录状态通知。通知使用低重要性通道，默认无声音、无角标。
3. 点击「允许忽略电池优化」，确认系统豁免。
4. 点击「允许自启动」，允许专注记录自启动。
5. 点击「应用省电设为无限制」，选择无限制。
6. 按「后台锁定 / 最近任务锁定」的指引锁定本应用，防止一键清理。小米官方给出的入口为手机管家 / 安全中心 → 设置 → 优化加速 → 锁定应用；部分版本也提供最近任务卡片上的锁形按钮。
7. 返回 App 后，手动勾选你已经完成的小米配置项，再开始采集。

小米专用页面属于厂商私有入口，版本变化时可能无法直接打开。客户端捕获打开失败并回退应用信息或手动指引；不将“成功打开设置”当作“已经授予权限”。自启动、无限制和后台锁定三项勾选仅为**用户手动确认**；使用情况权限、电池优化豁免、通知状态则实时从系统读取。

K90 / 澎湃 OS 3 的具体菜单位置、长期保活、耗电和清理行为需真机试用验证；当前开发环境没有连接此手机，不宣称已完成机型认证。

## 两个模式的实际区别

| 项目 | 小米优化 | 通用安卓 |
| --- | --- | --- |
| 持续采集 | 可见的 `specialUse` 前台服务 | 相同 |
| 亮屏采样 | 每秒读取使用事件 | 相同 |
| 熄屏采样 | 最多每 60 秒尝试读取，屏幕广播即时处理 | 最多每 30 秒尝试读取，屏幕广播即时处理 |
| 上传 | 默认 30 秒，应用切换立即上传可设置 | 相同 |
| 中断恢复 | 持久系统任务、开机恢复、事件回放 | 相同 |
| 小米配置 | 自启动 / 无限制作业入口、后台锁定指引、手动确认清单 | 通用权限与其他品牌指引 |
| 切换 | 保留设备、账户、采集进度和待上传队列 | 相同 |

这里采用共享采集核心与厂商配置策略，避免两套采集器产生重复记录。界面明确显示模式之间的能力差异。

保活不是“进程永远不退出”。前台服务可被系统回收；恢复任务至少间隔 15 分钟，实际执行受系统调度、省电状态与 Android 16 的任务配额影响。熄屏时不持有永久 CPU 唤醒锁，Doze 中上传可能延迟。恢复时从持久采集进度读取系统使用事件，最多尝试最近 48 小时，按事件起止时间补记录；系统使用事件通常只保留数天，缺失历史不能保证补全。事件与进度在同一 SQLite 事务中提交，已确认的片段不会重复计时。

“强行停止”、撤销使用情况权限、系统限制后台或超强省电仍可能阻止运行。系统强行停止后需要重新打开 App；重启后需要先解锁。App 内「暂停」保留上传服务，「停止后台服务」关闭自动恢复；关闭「重启并解锁后自动恢复」后，重启不会恢复服务。

## 与电脑端的功能对应

| 电脑端功能 | 安卓端实现 |
| --- | --- |
| 前台进程、应用名与时长 | 系统使用事件中的前台应用、包名、起止时间与时长，30 秒分段 |
| 实时前台显示 | 上传协议 `foreground` 快照，应用切换时可立即上报 |
| 锁屏与休眠停止计时 | 熄屏、系统锁屏停止；解锁后根据系统事件恢复 |
| 键鼠空闲阈值 | 普通安卓 App 无法读取其他应用的触摸活动，使用屏幕 / 锁屏状态适配 |
| 电量与电源状态 | 电池间隔采样、充电 / 拔电变化、启动、熄屏、解锁及关机节点 |
| 离线队列与补传 | SQLite WAL；500 条批次、确认后标记、固定事件 ID、指数退避、gzip 协商 |
| 公网 / 内网地址 | 主地址失败后尝试备用，后续优先使用成功地址；不跟随上传重定向 |
| 账户切换 | 主地址 + 已验证账户隔离设备 UUID 与队列；旧队列留存，切回后补传 |
| 应用名称与配色 | 按包名编辑、搜索可见已安装应用和最近应用、12 色、单项 / 全部恢复颜色、同步历史 |
| 托盘控制 | 常驻通知提供暂停 / 继续、上传、停止；点击通知回到 App |
| 最近记录与今日排行 | 原生总览与本机记录；已上传本机保留 7 天，待上传最多 30 天 / 全局 100,000 条 |
| 服务端管理 | 原生登录、生成密钥、管理员创建 / 启停成员与保留期限；管理会话仅在内存 |
| 完整看板与统计 | App 内 WebView 打开现有移动端网页，包括日 / 周 / 月 / 年、其他设备、公开范围与密码修改 |
| 深浅色主题 | 跟随系统 / 浅色 / 深色，记住本机选择；服务端网页保持自己的主题设置 |

安卓包名用于上传协议的 `process_name`。仅可见的启动器应用与最近记录用于应用选择，系统未向本应用公开的包会显示包名。电池剩余使用时间没有可靠系统值时上传空值。

## 试用检查

先在两个应用间切换，查看服务端当前应用和记录；再依次验证锁屏 10 分钟、退出界面 30 分钟、断网后使用再联网、切换保活模式、手机重启解锁，以及半天或一晚待机。确认熄屏没有累计应用时长、联网后队列减少、模式切换没有多出一台设备。关机时只保证尽力保存和补传，不保证最后一包能在断电前发出。

如发现掉线，在「保活 → 当前运行检查」查看服务、最近采集和恢复任务状态，并复制诊断信息。复制内容不含密钥或使用记录。请同时记录系统版本、保活模式，以及是系统清理、重启、断网还是普通后台待机触发。

## 源码构建

需要 JDK 21、Android SDK Platform 36、Build Tools 36.0.0；Gradle 固定 8.13、AGP 8.13.2。Android 16 的 Robolectric 启动测试需要 JDK 21。SDK 可由 Android Studio 或官方命令行工具安装。安装到项目的 `.runtime/android/sdk` 时可直接运行：

```powershell
.\android\build.ps1 -JdkPath 'C:\Program Files\Java\jdk-21.0.10'
```

SDK 在其他位置时加 `-SdkPath`。脚本执行发布构建、Lint、逻辑、本地 HTTP 和界面启动测试、签名验证及 SHA-256；Gradle 包装器校验发行包 SHA-256。Windows 非英文目录的 Gradle 测试工作进程有路径兼容问题，脚本使用 AGP 导出的完整测试类路径直接运行 JUnit。

启动与导航回归使用 Robolectric 4.16.1，在 API 28 / 30 / 36 分别验证未配置、未授权时首次启动、五个页面切换、深色主题、窗口重建、内置看板、快速连续切页、关闭系统动画和切页途中退到后台。首次测试会下载 Android 测试运行库，缓存位于 `.runtime/android/test-home`。Windows 原生测试库的临时目录需要可写且不含中文，默认使用系统临时目录，可用 `-TestTempPath` 指定。Robolectric 验证不替代 Redmi 真机的系统权限、后台运行和保活测试。

加 `-VerifyServer` 可用项目 `.runtime/build-venv` 中已安装的开发依赖启动独立临时服务端，测试真实 Java 客户端上传、去重、压缩、当前应用、名称 / 颜色、管理和密钥轮换；不会访问你的真实服务端。测试进程退出后清理临时数据库。

首次发布构建生成本地 RSA 3072 位签名密钥，保存在 `.runtime/android/signing/focusledger.jks`，密码配置为 `.runtime/android/signing.properties`，均不提交仓库。**务必备份这两处文件，后续 APK 覆盖升级需要同一签名**。Keystore 丢失将无法保留原包名覆盖升级，也会影响安装范围内设备识别的一致性。发布 APK 与校验文件位于 `android/release`。

## 方案依据

- [小米：自启动权限管理说明](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1624)：第三方应用需用户自行允许自启动。

- [Android：前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types#special-use)：持续、用户发起且可停止的使用记录采用 `specialUse`，与短时间的数据同步工作区分；应用商店发行需另行声明并审核用途。
- [Android：后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[UsageStatsManager](https://developer.android.com/reference/android/app/usage/UsageStatsManager)、[任务调度与电池限制](https://developer.android.com/develop/background-work/background-tasks/optimize-battery)。
- [三星后台休眠设置](https://www.samsung.com/us/support/answer/ANS10003442/)、[华为后台应用启动管理](https://consumer.huawei.com/en/support/content/en-us00428704/)：通用模式中的品牌指引依据，具体位置以系统版本为准。
